MeteSec aims to remain usable with a keyboard, screen magnification, common screen readers, and reduced-motion preferences.

The site uses semantic headings, visible focus indicators, descriptive link text, responsive layouts, colour contrast suitable for the dark and light themes, and alternatives for meaningful images. Decorative images are hidden from assistive technology. Motion is reduced when the browser requests it.

Accessibility is an ongoing process rather than a one-time badge. If a page, component, document, or code example creates a barrier, please report the URL and the problem through the [contact page](/contact/). Where possible, include the browser, assistive technology, and expected behaviour.
