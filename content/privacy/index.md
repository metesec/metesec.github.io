MeteSec is designed as a static website with minimal data collection.

## This site

MeteSec currently does not run advertising trackers, behavioural analytics, account systems, or a first-party comments database. Search runs in the browser using a static site index. The site does not intentionally set marketing cookies.

## Hosting

The site is hosted through GitHub Pages. As the hosting provider, GitHub may process technical request information such as IP addresses, timestamps, requested URLs, and browser details for security and delivery. See [GitHub's privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) for its practices.

## External links and services

Links to GitHub, LinkedIn, Ko-fi, newsletter providers, or other external sites take you to services with their own privacy policies. External widgets are not loaded unless they are explicitly enabled. If comments are enabled in the future, the article will load the configured discussion service and this page will be updated.

## Contact

If you contact MeteSec through an external platform, that platform processes the message under its own terms. Information you provide is used to respond to the request and is not sold.

This page will be updated before introducing analytics, an email subscription form, embedded third-party media, or another service that materially changes data processing.
